# `lixeira/` — Arquivo de Obsoletos e Ideias Descartadas

Esta pasta funciona como backup versionado de arquivos substituídos, rascunhos e ideias não implementadas, conforme a política do `PLANO_EVOLUCAO.md` §4 e `PROMPT_GERAL.md` §8.

## Regras
- Nunca apagar arquivos permanentes do projeto; mover obsoletos para `lixeira/AAAA-MM-DD/<caminho>`.
- Nenhum script em `scripts/` ou arquivo em `public/` pode importar ou ler desta pasta.
- A limpeza desta pasta é feita exclusivamente de forma manual pelo mantenedor.
