# `dados/perspectivas/` — Governança e Gabaritos de Perspectivas

Esta pasta armazena as diretrizes analíticas e os gabaritos das perspectivas avaliativas do Ranking Parlamentar (`PLANO_EVOLUCAO.md` §6).

## Arquivos
- `INSTRUCAO_PENSAMENTO.md`: guia de raciocínio legislativo para humanos e agentes de IA avaliarem projetos pelo efeito prático (sem cair em títulos enganosos ou destaques invertidos).
- `catalogo_perspectivas.json`: definição das perspectivas ativas e seus gabaritos por votação (`SIM` / `NAO` e peso `rp`), consumido diretamente por `scripts/calcular.py`.
